# Портфолио игр

Статический сайт со списком игр. Без сборки и зависимостей: HTML + CSS + один JS-файл.

## Структура

```
index.html            разметка страницы (каркас, контент подставляется скриптом)
assets/css/style.css  стили
assets/js/main.js     рендер карточек из данных
assets/img/           обложки игр (16:9)
data/games.json       ЕДИНСТВЕННЫЙ файл, который нужно править для добавления игры
.nojekyll             отключает обработку Jekyll на GitHub Pages
```

## Как добавить игру

1. Положить обложку в `assets/img/` (16:9, например 960×540, `.jpg` или `.webp`).
2. Дописать объект в массив `games` в `data/games.json`:

```json
{
  "id": "slug-igry",
  "title": "Название",
  "year": 2025,
  "status": "released",
  "engine": "Unity",
  "role": "Что делал",
  "platforms": ["WebGL", "Яндекс Игры"],
  "tags": ["жанр", "механика"],
  "cover": "assets/img/slug-igry.jpg",
  "summary": "Одна строка для карточки.",
  "description": "Подробности, пока не выводятся на странице.",
  "links": [{ "label": "Играть", "url": "https://...", "primary": true }]
}
```

Карточки сортируются по `year` от новых к старым. Фильтр над списком собирается
из `platforms` автоматически и прячется, если платформа всего одна.

## Локальный просмотр

Открывать `index.html` двойным кликом нельзя — браузер запретит `fetch` к JSON.
Нужен любой локальный сервер:

```bash
python -m http.server 8000
# затем http://localhost:8000
```

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и запушить эту папку в ветку `main`.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<username>.github.io/<repo>/`.

Все пути в проекте относительные, поэтому сайт работает и в подпапке репозитория,
и на корневом домене `<username>.github.io`.
