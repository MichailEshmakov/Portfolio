# Портфолио игр

Сайт со списком моих проектов: что за игра, какой год, какая у меня была роль,
на чём сделано, где поиграть.

### 👉 [michaileshmakov.github.io/Portfolio](https://michaileshmakov.github.io/Portfolio/)

---

## Как пользоваться

Сверху панель, которой список подгоняется под себя.

- **Поиск** — по всему сразу: название, жанр, технологии, площадка.
  Несколько слов через пробел ищутся вместе.
- **Жанр** и **Кроме жанра** — оставить нужные жанры или, наоборот, убрать
  лишние. В каждый можно набрать несколько: выбранное появляется чипсой снизу,
  клик по ней снимает выбор.
- **Роль**, **2D / 3D**, **Найм**, **Площадка** — фильтры по одному значению.
- **Важность от** — ползунок. Я сам расставил проектам оценки, поэтому
  по умолчанию видны те, которые стоит посмотреть в первую очередь.
  Сдвиньте ползунок влево, чтобы показать остальные.
- **Сортировка** — сначала важность или сначала год.
- **Технологии** — кнопка, которая раскрывает стек во всех карточках сразу.
- **Сброс** — вернуть всё как было.

Ещё на странице есть переключатель тёмной и светлой темы (в правом верхнем
углу) и стрелки для быстрого перехода между блоками.

**Любая выборка — это ссылка.** Поиск, фильтры и сортировка попадают в адрес
страницы, так что настроенным списком можно просто поделиться.
