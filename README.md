# Портфолио игр

Сайт со списком моих проектов: что за игра, какой год, какая у меня была роль,
на чём сделано, где поиграть.

### 👉 [michaileshmakov.github.io/Portfolio](https://michaileshmakov.github.io/Portfolio/)

---

Список настраивается панелью сверху: поиск по всем полям сразу и фильтры
по жанру, роли, площадке и прочему.

Пара мелочей, которые по самой странице не видны:

- Я оценил проекты по важности, и сначала страница показывает только лучшие.
  Чтобы увидеть все игры, сдвиньте ползунок «Важность от» в крайнее левое
  положение.
- Поиск, фильтры и сортировка попадают в адрес страницы — получившимся списком
  можно поделиться ссылкой.
