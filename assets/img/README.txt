Картинки игр, которые лежат рядом с сайтом.

Что где:
  <год>/<Игра> Icon.png        — иконка, показывается в шапке карточки
  <год>/<Игра> Screenshot.gif  — скрин, показывается в галерее карточки
  images.json                  — какому названию из таблицы какие файлы достались

Папки с годами — просто для порядка, сайт на них не смотрит: год берётся
из таблицы, а картинки — из images.json. Поэтому файл может лежать
в папке 2014, а игра стоять в таблице 2013 годом — это нормально.

Как добавить картинку:
  1. положить файл в папку года;
  2. в images.json дописать строку, где ключ — название игры ровно как
     в колонке «Игра» гугл-таблицы:

     "Название из таблицы": {
       "icon":  "2026/Game Icon.png",
       "shots": ["2026/Game Screenshot.gif"]
     }

Регистр, ё/е и лишние пробелы в ключе не важны. Если название в таблице
подрежут до первой точки или двоеточия («Крутой побег. Обби, блин.» →
«Крутой побег»), картинки всё равно найдутся.

Второй способ, без этого файла: написать имя файла прямо в колонке
«Скрины» гугл-таблицы (например «2026/Gdetto Screenshot.png»). Оба
способа работают одновременно, картинки складываются.
